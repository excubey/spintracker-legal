# SpinTracker — Legal

Public hosting for the SpinTracker iOS app's legal documents, served via GitHub Pages.

- **Privacy Policy** — https://excubey.github.io/spintracker-legal/privacy-policy.html

This repo contains published output only. The **source of truth** is
`docs/legal/privacy-policy.md` in the (private) SpinTracker app repo — edit
there first, then regenerate the HTML here, so the app's in-app policy view and
the hosted page cannot drift apart.
